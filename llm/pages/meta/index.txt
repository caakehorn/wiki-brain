# meta — index

The wiki describing itself rather than Dan. Three kinds of page live here: the
on-site mirrors of the root reading aids, the cross-model skills database, and
curated cross-domain journeys.

## Reading aids

Generated by `bin/wiki-digest` from the rest of the corpus — mirrors of
`DIGEST.md`, `RECENT.md`, `OPEN.md` at the repo root, given a `wiki/` address
so the portal actually serves them (its sync only reads `wiki/**` and
`sage/questions/**`).

- [[wiki/meta/digest]] — the front door: counts, altitude, the top of both lists below
- [[wiki/meta/recent-activity]] — what changed lately, and why
- [[wiki/meta/open-questions]] — every unresolved contradiction, gap and prediction

## The skills database

Not about Dan at all — about the machines that write these pages. Several
models work on this repository and none can see what the others have; this is
the shared record they push their skills, MCP servers, plugin tools and
subagents into. Generated by `bin/wiki-skills page` from an append-only log
under `skills/registry/`.

- [[wiki/meta/skills]] — every capability on the record, and how a model adds to it
